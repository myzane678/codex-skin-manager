# 未验证 Codex 版本探针回退设计

## 目标

Codex 包版本不再作为主题注入的硬门槛。精确命中已验证版本时沿用对应适配器；未知版本使用最新适配器进行实时 DOM 探针，探针通过即注入，探针失败才进入兼容性降级。

## 运行时行为

- 版本选择结果同时包含适配器和 `verified` 标记。
- 已验证版本精确选择原适配器，状态标记为 `verified`。
- 未验证版本选择最新适配器，状态标记为 `unverified`。
- CDP 自动附加不再因未知版本提前退出，统一交给运行时探针裁决。
- 壳层、导航、主区域或原生控件探针不通过时不注入，保留兼容性降级保护。
- 注入、回滚、重连与主题热切换仍由现有 `ThemeRuntimeCoordinator` 负责。

## 客户端提示

注入成功且版本未验证时：

- 左侧当前主题状态显示“已应用 · 未验证版本 · CDP 已连接”。
- “启动与代理”页显示常驻黄色提醒，说明当前版本已通过实时探针但尚未正式验证。
- 不弹窗、不要求确认、不阻断自动注入。

精确版本命中时不显示提醒。实时探针失败时仍显示“兼容性降级”，不把失败伪装为警告。

## 状态与诊断

运行时状态增加独立的兼容性字段 `verified | unverified`，避免复用错误码表达成功但有风险的状态。诊断文本记录该字段；错误码只保留真实失败。

## 验证

- 单元测试覆盖精确版本和未知版本的适配器选择。
- 协调器测试覆盖未知版本探针通过后成功注入并上报 `unverified`。
- 自动附加测试覆盖未知版本仍发起附加。
- 渲染测试覆盖侧栏状态和常驻提醒。
- 真实 `127.0.0.1:9229` 验证当前 `26.721.11231.0` 可产生注入样式与运行 ID。
