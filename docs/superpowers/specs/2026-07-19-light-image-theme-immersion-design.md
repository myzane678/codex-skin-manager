# 浅色图片主题沉浸感设计

## 目标

让带有 `readability: 'light'` 背景图片的主题在 Codex 壳层中清晰呈现图片，同时保持顶栏、侧栏和文本的可读性。

## 范围

- 仅调整 `compileInjectionPlan` 对“有背景且为浅色可读性”的固定 CSS token。
- 顶栏、侧栏、导航继续使用较高不透明度的浅色玻璃表面。
- 主内容区使用更低不透明度的浅色玻璃表面，让根节点背景图片在主体区域更明显。
- 根节点背景遮罩从当前较重的浅色遮罩改为较轻的固定遮罩。
- 无背景主题、深色背景主题、显式 `shell` token 和运行时注入/回滚流程保持不变。

## 视觉规则

- 浅色图片背景的根遮罩固定为 `rgba(244,247,250,0.48)`。
- 该主题的顶栏、侧栏和导航固定为 `rgba(244,247,250,0.76)`。
- 该主题的 `main` 固定为 `rgba(244,247,250,0.42)`。
- 仍使用既有文字颜色、边框颜色和 `blur(14px)`，不新增选择器、不触碰控件节点。

## 实现边界

- 在编译器内部以背景存在性和 `readability` 决定固定 surface token；主题 manifest 不新增字段。
- 保持所有 CSS 以当前 `data-codex-skin` 运行 ID 作用域生成。
- 不处理当前工作区的 `Welcome` 装饰误判；它属于独立的欢迎页探测问题。

## 测试与验收

- 新测试断言浅色图片主题产生较轻根遮罩、顶栏/侧栏玻璃层与更透明的主区玻璃层。
- 新测试断言无背景主题继续使用既有浅色默认表面值。
- 执行 `npm test -- --run tests/unit/compiler.test.ts`、`npm run typecheck`、`npm run lint`、`npm test -- --run` 和 `git diff --check`。
- 用户重新启动主题版后，用只读 CDP 确认根标记和样式存在，并确认 `main` 的计算背景比顶栏与侧栏更透明。
