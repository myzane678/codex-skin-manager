# 本地图片主题创建器设计

## 目标

让用户在 Codex Skin Manager 的主题库中选择一张本地 PNG、JPEG 或 WebP 图片，由管理器完全离线地分析图片、生成可编辑的主题建议，并创建、启用和导出与现有导入主题相同格式的 `.codextheme` 主题包。

## 用户流程

1. 用户点击“从图片创建主题”，选择一张本地图片；也可将单张本地图片拖入主题库的拖放区域。
2. 主进程校验格式与大小，压缩输出为最大 `2560×1440`、WebP、质量 `82` 的背景图；原图不复制到主题目录。
3. 主进程对缩略像素进行本地分析，返回：三枚候选强调色、默认强调色、浅色或深色可读性建议、默认背景焦点 `(50, 50)` 与背景预览 data URL。
4. 用户填写主题名称，并可选择候选强调色或输入合法六位十六进制颜色、切换明暗可读性、调整焦点横纵坐标。
5. 点击“创建主题”后，主进程仅使用已分析的图片暂存文件和受控参数生成主题包、计算 SHA-256、安装到应用数据目录，并返回最新主题快照。
6. 主题卡片提供“导出主题包”操作，用户指定保存路径后得到可导入的 `.codextheme` 文件。

## 数据和边界

### 图片输入

- 文件选择框与拖放区域仅接受一张 `.png`、`.jpg`、`.jpeg`、`.webp` 文件。
- 输入文件最大 20 MiB，解码后像素总数最大 36,000,000；不接受 GIF、SVG、网络 URL、路径字符串或渲染进程传入的二进制。
- preload 只通过 Electron `webUtils.getPathForFile()` 从拖放事件的首个 `File` 取得路径，并将其交给专用 IPC；渲染进程不读取原始字节。主进程拒绝空路径、非字符串或多文件输入。拖放不绕过既有格式、大小、像素和图片解码校验。
- 一次图片分析产生一个随机令牌和仅位于应用数据临时目录的 WebP 文件；令牌在创建后即删除，应用退出时清理过期暂存文件。

### 分析结果

- 使用 `sharp` 在 Electron 主进程本地处理图片。
- 将图片缩放到不超过 `96×96` 的像素样本，忽略透明像素与低饱和近灰色像素；量化为 RGB 色桶并选取前三个出现频率最高的不同色相。
- 默认强调色选取三个候选中与建议 surface 对比度最高的一枚；候选不足时用图像平均色的互补高饱和度色补足。
- 使用感知亮度均值：亮度低于 `0.52` 推荐 `dark`，否则推荐 `light`。
- 默认焦点固定 `50/50`。首版不尝试识别人脸或主体，避免引入本地模型或云端服务。

### 主题创建

- ID 由主题名称转换为 kebab-case，空名使用 `picture-theme`；若已存在，追加短随机后缀。
- 版本固定为 `1.0.0`，作者为 `本地创建`，来源仍为 `unknown`。
- 背景资源固定为 `assets/background.webp`；`background` 使用用户确认的 accent、readability、focusX、focusY，placement 固定为 `cover`。
- 预览资源是同一 WebP 的缩略副本 `preview.webp`，最大 `640×360`、质量 `76`；背景与预览均记录 SHA-256。
- 生成 ZIP 后调用现有 `importThemePackage()` 安装，确保创建和导入共享完整校验、原子落盘和版本冲突逻辑。

### IPC

- `theme:analyze-image`：主进程打开选择对话框并返回受控 `ImageThemeDraft`；取消时返回 `null`。
- `theme:analyze-image-path`：接收一个由 Electron 拖放事件产生的本地文件路径，主进程复用既有图片分析；无效参数返回 `IPC_ARGUMENT_INVALID`。
- `theme:create-from-image`：接收严格校验的 token、名称、accent、readability、整数焦点；返回 `ManagerSnapshot`。
- `theme:export`：接收 `ThemeIdentity`，主进程打开保存对话框并写出该安装目录中的 `package.codextheme`；取消时不修改主题库。
- 渲染进程不接触本地路径、原始图片字节、哈希、压缩器或 ZIP 内容。

## 界面

- 主题库标题栏并列显示“从图片创建主题”和现有“导入主题包”；主题列表区域可作为拖放区域，拖入时展示高亮边框和“松开以创建主题”提示。
- 拖入多张文件、非图片或处理失败时显示既有错误提示，不创建草稿或主题；拖放期间和图片分析期间禁用再次发起拖放。
- 创建器是主题库内的单页表单：预览、名称、三枚候选强调色、十六进制输入框、明暗切换、两个范围滑块和“创建主题/取消”。
- 打开图片但尚未创建时不会产生主题库条目；创建失败时显示可读错误并保留草稿，允许修改后重试。
- `ThemeCard` 增加导出图标，活动主题同样允许导出。

## 安全与回滚

- 图片从始至终在本地处理，不联网、不调用云端模型、不保留原图。
- 分析和创建前都验证令牌、格式、尺寸、颜色和坐标；令牌与暂存文件不匹配、过期或缺失时拒绝。
- 创建任一步失败时删除新 ZIP 与暂存输出，已有主题和当前启用状态不变。
- 生成的主题通过现有 manifest/资源/哈希验证；不开放任意 CSS、脚本、URL 或自定义选择器。

## 验收与测试

- 单元测试覆盖图片格式/大小/像素拒绝、色彩候选与浅深建议、令牌生命周期、创建后可由现有导入器读取、导出包可再次导入。
- IPC 参数测试覆盖无效 token、非法颜色、非整数或越界焦点和未知主题身份。
- 渲染测试覆盖创建入口、拖入单张图片、拒绝多文件拖入、草稿预览、候选色选择、创建调用、取消和导出动作。
- 运行 `npm run typecheck`、`npm run lint`、`npm test -- --run` 与 `npm run package`。
- 人工验收：使用一张本地图片创建、启用、启动主题版并确认欢迎页背景可读；导出后在另一空主题目录重新导入；原图不出现在应用主题目录。
