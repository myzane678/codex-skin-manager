# 内置纯色主题设计

## 目标

让没有背景图片的内置主题也能在 Codex 中产生清晰、低干扰的配色效果，并保持现有图片主题的视觉行为不变。

## 方案

- 无背景主题使用其受控的 `variables.accent` 生成轻量 CSS。
- CSS 仅作用于已验证的 Codex 壳层：页面底色、左侧栏、主内容层、边框和悬停强调色。
- 注入运行时仍负责验证壳层和实时切换；不新增权限、端口或主题资产。
- 有背景主题继续使用 Dream Skin 图片 CSS，不混入纯色主题规则。

## 验收

- 四个内置主题在运行中的 Codex++ 会话中切换后具有非空 CSS。
- CSS 包含主题的强调色，并只命中已验证的壳层选择器。
- 图片主题仍包含背景图片变量，且不包含纯色主题选择器。
