# 仅背景主题全局边界设计

## 目标

所有主题只负责提供背景图片及其展示方式，不接管 Codex 官方界面的布局、字体、文字颜色或控件外观。该边界适用于首页、普通任务页和其他被运行时识别的页面，也适用于标准图与宽图主题。

## 设计

- 有背景图片的主题仅生成背景相关 CSS：图片、定位、裁切、重复方式、固定方式，以及为了露出图片所需的受控表面背景或渐变。
- 允许对稳定壳层锚点 `body`、`aside.app-shell-left-panel`、`main.main-surface`、直属 `header.app-header-tint` 和 `[role="main"]` 设置 `background` 系列属性。
- 不生成字体、字号、字重、行高、文字颜色、光标颜色、边框、阴影、模糊、尺寸、间距、定位、对齐、变换、过渡或显示状态覆盖。
- 不选择 `button`、`input`、`textarea`、编辑器、消息、建议卡或其他官方控件。
- 不再向官方 DOM 追加欢迎语装饰节点。
- 没有背景图片的旧主题保留导入兼容和字段校验，但运行时不再用其强调色、壳层或文案字段改写官方界面，因此生成空样式且不生成装饰。
- 现有 manifest 字段暂不删除，避免破坏旧主题包兼容；它们在此边界下不产生界面样式。

## 页面策略

- 首页：在 `body` 绘制一次固定背景；标准图使用较高不透明度的官方表面色混合层，宽图使用较轻的横向渐变层。
- 任务及其他路由：仅在 `taskMode` 为 `ambient` 或 `banner` 时绘制固定背景，并使用同类壳层背景；`off` 不绘制任务页背景。
- 顶栏只处理背景透明度，不改变任何文字、图标、边框或几何属性。
- 输入框和其他控件完全保留官方样式。

## 验收标准

- 编译结果包含受控本地图片 URL、焦点位置和 `cover` 背景。
- 图片主题 CSS 不含控件选择器及非背景视觉或布局声明。
- 无图片主题生成空 CSS，且所有主题的 `decoration` 均为 `null`。
- 不降低已有输入校验、安全 URL 校验、路由标记和精确回滚能力。
- 类型检查、Lint、全量测试和 `git diff --check` 全部通过。
